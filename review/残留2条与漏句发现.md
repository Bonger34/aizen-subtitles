# 最后 2 条残留的扩窗扫描 + 一个更大的发现

## 一、那 2 条残留:确认是噪声条目

对 `P22 17m53s [口]`、`P24 18m11s [敬告]` 做了分档扩窗密集扫描
(±10s@0.25s → ±30s@0.5s → ±120s@1s;4 种裁剪(字幕带/下半屏/上部/整屏) × 3 种阈值):

**目标文本在 ±120 秒窗口内 0 次命中。** 画面本身也没有字幕(两条目标秒的画面均为纯战斗/厂房镜头)。

→ 这两条是当年 OCR 在无字幕画面上产生的噪声条目,**建议删除**(删掉即 7003 条)。

## 二、顺带发现:窗口里有 3 条台词,库里真的没有

这次扫描是"±120s 内逐帧检字幕区间 → 每区间 OCR 峰值帧 → 与库对照"。
在 P22(15m53s–19m53s)与 P24(16m11s–20m11s)共 480 秒里,查出 3 条**全库检索 0 命中**的台词:

| 位置 | 台词 | 画面核实 |
|---|---|---|
| P22 16m06s | 休想得逞 | ✅ 已目视 |
| P22 16m50s | 勇海 我们上 | ✅ 已目视 |
| P24 17m14s | 明白发射牵引光束 | ✅ 已目视 |

三条均已补入库(7002 → **7005**)。

### 为什么值得注意

复现当年扫描的读取方式(字幕带 y895-985 裁剪 + `>245` 二值化 + OCR)后:

| 位置 | 带内白占比(阈值 0.02) | 复现 OCR |
|---|---|---|
| P22 16m06s | 0.028 | 休想得逞 ✅ |
| P22 16m50s | 0.031 | 勇海我们上 ✅ |
| P24 17m14s | 0.054 | 明白发射牵引光束 ✅ |

即**当年完全读得出来**(白占比高于阈值、OCR 正确),**但库里就是没有**。
三条时长都只有 ~0.7 秒(1.0 秒后画面已无字幕),属于短句。

### 含义

- 之前"真漏句 = 0"的结论是在 **P01/P13 两集**上做的 0.17s 下探,不能推广到全系列;
- 本次 480 秒样本中就有 3 条真漏,**漏收率量级约 1%~3%**(样本小,仅作量级参考);
- 这类漏句都是**短句(~0.7s)**,且与"读不出"无关,更像是建库环节的丢失。
