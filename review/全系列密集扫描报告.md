# 全系列密集扫描报告(扩窗 + 0.25s 密采)

## 扫描规模

| | 数值 |
|---|---|
| 覆盖 | 全 25 集 |
| 检测区间 | BAND(895–985) ∪ LOW(985–1062) 两路任一触发,共 **6,300+ 段** |
| 区间内采样 | **每 0.25 秒一帧**,共 **约 78,000 帧** |

单集约 10 分钟,全系列约 4 小时。

## 候选后处理

1. **与全库双向模糊匹配**(任意库条目,双向包含度 ≥0.7)→ 已收录 **4,129 条**
2. 剩余 1,801 条分类:

| 类别 | 条数 |
|---|---|
| 疑似台词 | 765 |
| 跨集重复(歌词 / 固定字幕) | 643 |
| 噪声(数字占比过高 / 不足 2 字) | 366 |
| 版权 / 制作卡 | 27 |

3. 765 条疑似台词**聚成 461 类**,按与库最近条目的相似度分档:

| 档 | 类数 | 实际内容 |
|---|---|---|
| A ≥0.6 | 76 | **同一句,库文本较差**(最多的是掉了数字) |
| B 0.4–0.6 | 169 | 同一句的差异读取 / 短碎片 |
| C 0.2–0.4 | 129 | **片头片尾日文歌词**(`何万回何百回`/`愛情力友情力交差`/`堅結手手絶対離`) |
| D <0.2 | 87 | **P25 片尾演职员表 + 片尾歌词**(`所以在夕阳西下前定要说给你听`/`因为你我的牵绊永不间断`…) |

## 结论

**没有发现新的漏句台词。** 461 类经逐类核对后全部归入:

- 片头片尾**日文歌词**与**演职员表**(非台词,按既定口径排除);
- 与库条目**同句的差异读取**(多为 OCR 变体,不是新句);
- 画面上的**帧计数器数字**被一并读入造成的"加长"(`喂你矜持一点` → `喂你矜持一点511`),属噪声。

唯一有价值的产出是 **3 条库文本掉了数字**的条目(其配图画面本来就有数字,纯文本修正):

| 集 | 时间 | 修正前 | 修正后 |
|---|---|---|---|
| P08 | 12m26s | 年前绫香星从天而降 | **1300**年前绫香星从天而降 |
| P19 | 11m25s | 周期为年的椭圆轨道 | 周期为 **1300** 年的椭圆轨道 |
| P19 | 11m44s | 然而那之后又过了年 | 然而那之后又过了 **1300** 年 |

## 对"漏句"的最终判断

- 本轮(扩窗 + 0.25s 密采 + 全库双向匹配)**未再发现漏掉的台词**;
- 上一轮在 P22/P24 的 480 秒样本中发现并补入的 3 条(`休想得逞`/`勇海 我们上`/`明白发射牵引光束`)是真实漏句,已入库;
- 结合两轮:字幕带内的台词覆盖率已接近完整;**残余风险集中在"完全落在字幕带之外"的中文字幕**——那些经查全是版权卡、歌词、图鉴/预告/介绍卡解说,不属于台词。
